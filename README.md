# MTG Arena Event EV Calculator

A lightweight, client-side Expected Value (EV) calculator for Magic: The Gathering Arena events (Drafts, Sealed, Constructed events, etc.).

## Features

- **Pre-configured Presets**: Premier Draft, Traditional Draft, Quick Draft, Standard/Alchemy Events, Sealed, etc.
- **Custom Event Builder**: Set structure (Single / Best of 3), max wins, max losses, entry fees, and custom reward tiers.
- **Valuation Controls**: Customize currency valuations (Gems, Gold, Packs, Play-In Points, Qualifier Badges).
- **Comprehensive EV Analytics**: Win-rate step matrix (30%–70%), win distribution, break-even analysis, and net value highlighting.
- **Auto-Saving & Theming**: Automatically persists adjustments to browser cache with 6 MTG land-color themes.

## Usage

Simply open `index.html` in any modern web browser or serve locally:

```bash
python3 -m http.server 3000
```
